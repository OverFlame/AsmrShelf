链路已通，入口是作品工具条的 `track-fetch-dlsite`（首页工具条只在作品层之外渲染，入口必须在作品里）：

| 步骤 | 代码 | 行为 |

## 8. 环境与命令

`DSH` 的 `bash -c` 不读 zsh 配置，环境变量必须与命令写在同一条。

```bash
export PATH="$HOME/flutter/bin:$PATH" LD_LIBRARY_PATH="$HOME/.local/lib" \
  FLUTTER_STORAGE_BASE_URL=https://storage.flutter-io.cn \
  PUB_HOSTED_URL=https://pub.flutter-io.cn
```

构建 Linux 产物时加 `NO_XIPH_LIBS=1`，否则 flutter_soloud 会去链 Opus 与 Ogg。
